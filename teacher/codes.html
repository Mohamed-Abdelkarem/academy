إزاي تحطه في الموقع

  1. افتح config/access-codes.js على GitHub (القلم = تعديل).
  2. الصق السطر جوه القايمة ACCESS_CODES (ولو بتغيّر كود قديم، امسح بتاعه).
  3. Commit changes. الموقع بيتحدّث بعد دقيقة أو اتنين.

أو ابعت لـ Claude: "غيّر كود حصة 3 لـ …" وهو يعملها.
